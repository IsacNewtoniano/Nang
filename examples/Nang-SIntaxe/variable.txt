  u16, i16, f16, u32, i32, f32

  import (Specific Compile Pointer)

simple AND Default Types:
  Type = simple AND Default Types for example

  Sintaxe:

    ┌─ immutable/mutable
    imut/mut Type Var = 3.58 ─> Value of Variable
             |    └─ Name of Variable
             └─ Type of Variable

             ┌─ Logic Type
    imut/mut Type: Size.byte Var = 1
                   └─ Physical Space

              ┌─ Size of Fixed-Array
              |       ┌─ Use bit for Compact Elements (use multiples of 8)
    imut/mut [35]Type: Size.byte/Size.bit Var = {0} ─> initialization value
                                       └─ Elements or Initialization Value

  Example(Code):

    ┌─ mutable
    mut f8 Var = 3.58 ─> Value of Variable
        |  └─ Name of Variable
        └─ Type of Variable

         ┌─ Logic Type
    imut u1: 1.byte Var = 1
             └─ Physical Space

         ┌─ Size of Fixed-Array
         |         ┌─ Use bit for Compact Elements (use multiples of 8)
    mut [5]u7: 7.bit Var = {0} ─> initialization value
               |              └─ Elements or Initialization Value
               └─ Save 32 bits

  Example(Clear):
    mut f8 Var = 3.58 ─> Value of Variable

    imut u1: 1.byte Var = 1
